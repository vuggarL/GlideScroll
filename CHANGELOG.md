# Changelog

All notable changes to GlideScroll will be documented in this file.

## [1.0.0] - 31.01.2026

### Added
- Initial release
- Smooth middle-mouse scrolling
- Horizontal scroll support
- Axis locking to prevent drift
- Four presets: Fine, Normal, Fast, Turbo
- Click vs hold detection
- Visual scroll indicator
- High DPI support
- High precision timing (1ms)
- Emergency cursor restore (Ctrl+Alt+R)
- Global toggle (Win+MButton)
- Autostart with Windows option
- Settings persistence via INI file
